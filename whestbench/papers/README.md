## Manuscript boundary

The public source tree intentionally does not include unreviewed manuscript
attachments. Add a paper PDF only after its title, author metadata, bibliography,
scope language, and evidence labels have passed the release check.

The recommended framing is the limits of static cubature for deep-ReLU Gaussian
integration, with the Kerdock result as a scoped contribution. Do not use the
repository to publish outreach drafts, reviewer contact lists, or private review
correspondence.
