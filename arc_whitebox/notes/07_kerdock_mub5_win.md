# A structured spherical 5-design beats the sampler

## Result

The winning estimator is a deterministic 66,048-point spherical 5-design
formed from the maximal set of 129 real mutually unbiased bases (MUBs) in
dimension 256. The 128 non-coordinate bases are generated by the binary
Kerdock code; the coordinate basis supplies the 129th. Each vector and its
antipode are included.

The frozen submission scores:

| evaluation | raw final-layer MSE | adjusted score |
|---|---:|---:|
| selection, IDs 0--49 | 1.75874633e-7 | -- |
| frozen holdout, IDs 50--99 | 2.80643696e-7 | -- |
| official full 100 | 2.28259133e-7 | **2.25656459e-7** |
| previous full-100 best | 3.56809476e-7 | 3.46069946e-7 |

This is a 34.8% reduction in adjusted score, or a 1.53x improvement. The
official local run used `whestbench==0.13.0` and `flopscope==0.9.1`, incurred
zero failures, and stayed below the 272B budget.

## Why this was not another sampling tweak

The earlier sampler spent essentially the whole budget on two scrambled Sobol
point sets. More points were not available, and ordinary control variates,
whitening, active subspaces, and moment propagation either failed or delivered
small improvements. The useful change was to stop treating the angular
integral as a generic high-dimensional sampling problem.

The network is positively homogeneous:

```
f(r u) = r f(u),   r >= 0.
```

For a standard Gaussian `X = R U`, with `U` uniform on the unit sphere and
`R` independent of `U`,

```
E[f(X)] = E[R] E[f(U)].
```

The radial variable can therefore be integrated exactly by evaluating every
sphere direction at radius

```
E[chi_256] =
sqrt(2) Gamma(257/2) / Gamma(256/2).
```

The remaining problem is angular cubature for a piecewise-linear homogeneous
function. Antipodes remove all odd spherical harmonics. A maximal real MUB
design also integrates the degree-2 and degree-4 harmonics exactly, so the
first possible angular error is degree 6.

## Construction

Write the ambient vector space as `GF(2)^8 = GF(2^7) x GF(2)`. Carlet's field
description of a Kerdock representative uses `m=7`, `t=3`:

```
f(x, x_8) =
  Tr(x^3 + x^5 + x^9) + x_8 Tr(x),

f_u(x, x_8) = f(u x, x_8),  u in GF(2^7).
```

The implementation uses `GF(2^7)` with irreducible polynomial
`z^7 + z + 1`. Mapping the 256 values of `f_u` to signs gives a chirp
`c_u`. The corresponding orthonormal basis is

```
B_u = H diag(c_u) / sqrt(256),
```

where `H` is the unnormalized 256-point Walsh-Hadamard matrix. There are 128
such bases. Distinct bases are mutually unbiased:

```
|<b, b'>| = 1/sqrt(256).
```

Adding the coordinate basis and antipodes produces

```
2 * 256 * (128 + 1) = 66,048
```

equal-weight directions.

The research harness verifies zero mean, covariance `I/256`, all relevant
fourth-moment permutation classes, random distinct-index fourth moments, and
the cross-basis MUB inner products before evaluating any network. An
independent audit additionally checks the field inverses, all 8,128
nontrivial pairs of Kerdock bases by exact integer Walsh spectra, and equality
of the fourth frame potential with the spherical target (`49,536`).

## How 66,048 points fit under budget

A conventional dense forward for all 66,048 rows is slightly over budget.
The first layer is the escape hatch, but it is a mathematical factorization,
not untracked work.

For a Kerdock basis,

```
B_u W_1 = H (diag(c_u) W_1) / sqrt(256).
```

All 128 products can be computed with tracked batched fast Walsh-Hadamard
transforms. Rotating the design by the frozen orthogonal matrix `Q` is folded
into the first weight as `Q W_1`; the 31 remaining layers are ordinary dense
tracked matrix products. The coordinate basis is evaluated directly from
`Q W_1`.

Official full-100 compute:

| quantity | value |
|---|---:|
| tracked FLOPs per network | 268,835,176,704 |
| mean effective compute | 268,898,960,582 |
| budget | 272,000,000,000 |
| mean score multiplier | 0.98859912 |

The structured estimator and the dense research implementation agree within
float-association noise.

## Experimental protocol

1. Build and algebraically validate the canonical design.
2. Evaluate the unrotated design and rotation seeds 0--7 on official IDs
   0--9.
3. Advance seeds 0, 1, 3, and 5 to IDs 10--49.
4. Freeze seed 3, the best aggregate result over IDs 0--49.
5. Open IDs 50--99 exactly once. The raw MSE is `2.80643696e-7`, versus
   `3.74299369e-7` for the previous method on the same holdout.
6. Implement the structured first layer, validate it in a clean subprocess,
   package it, and run the official full-100 harness.

The full-100 raw MSE reconstructed independently from the two halves is
`2.28259165e-7`, agreeing with the official structured result
`2.28259133e-7`.

## Negative paths that informed the pivot

- A kernelized boundary/Laplacian estimator based on
  `E[f(X)] = E[Delta f(X)]` for degree-1 homogeneous CPWL functions was
  10,000--100,000 times worse at equal cost. Rare switching surfaces are too
  difficult to estimate by naive bandwidth localization.
- Interlaced order-2 digital nets were 1.301x worse in cross-validation.
- A degree-2 spherical-harmonic kernel control functional reached only a
  0.984x factor.
- Exact layer-1 cross-fitted controls reached 0.928x before their compute cost
  erased much of the gain.
- Observable-projected K3/K4 skeleton propagation delivered a large relative
  gain over its own baseline but remained roughly 10x worse than the sampler.
- The energy-weighted K3 hierarchy and shrinkage were robust, but their
  deployable moment approximation was still not competitive with direct
  cubature.
