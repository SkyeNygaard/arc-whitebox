# Block-trace relaxation: abstract sharpness and point-evaluation equality

**Date:** 2026-07-30

## 1. Setup

Let

\[
V=\bigoplus_{j=1}^J H_{\ell_j},\qquad
A=\operatorname{diag}(a_j I_{d_j}),\qquad a_j\ge0,
\]

and use the weighted evaluation feature map

\[
\Phi_a(x)=\bigoplus_j \sqrt{a_j}\,Y_{\ell_j}(x).
\]

For a mass-one signed rule `Q=sum_i w_i delta_{x_i}`, define

\[
M_Q=\sum_iw_i\Phi_a(x_i)\Phi_a(x_i)^T.
\]

The target spherical moment matrix is `A`. Put

\[
T=\operatorname{tr}A=\sum_j a_jd_j,
\qquad
S_2=\operatorname{tr}(A^2)=\sum_j a_j^2d_j.
\]

The addition formula gives the **individual block traces**

\[
\operatorname{tr}(M_{Q,jj})=a_jd_j.
\]

Hence `tr(M_Q)=T` and `tr(A M_Q)=S_2`. Since `rank(M_Q)<=N`,

\[
\|A-M_Q\|_F^2
=\|M_Q\|_F^2-S_2
\ge {T^2\over N}-S_2.
\]

This is the general block-trace bound used in the final signed certificate.

## 2. The abstract relaxation is exactly sharp

Assume

\[
q_j={Na_j\over T}\in[0,1]
\]

for every active block. Form a diagonal vector containing `d_j` copies of `q_j`. Its entries lie in `[0,1]` and sum to `N`. It is therefore majorized by the eigenvalue vector with `N` ones and all remaining entries zero.

By the finite-dimensional Schur-Horn theorem, there is a rank-`N` orthogonal projection `P` with this diagonal. Its block traces are

\[
\operatorname{tr}(P_{jj})={Na_jd_j\over T}.
\]

Then

\[
M={T\over N}P
\]

has exactly the required block traces, rank `N`, and

\[
\|A-M\|_F^2={T^2\over N}-S_2.
\]

Thus **rank plus all individual block traces cannot yield a stronger universal matrix bound**. Every released adjacent profile satisfies the required condition; the verification artifact checks it component by component.

This does not show that the abstract optimizer is generated by spherical point evaluations. It shows precisely that further progress must use those evaluation constraints.

## 3. Equality for an actual atomic evaluation rule

Suppose a rule with `m<=N` nonzero weights attains the `N`-rank floor. Equality forces:

1. `m=N` and `rank(M_Q)=N`;
2. all nonzero eigenvalues of `M_Q` equal `c=T/N`;
3. therefore `M_Q^2=cM_Q`.

Let `E` be the `N x dim(V)` evaluation matrix with row `Phi_a(x_i)^T`, let `W=diag(w_i)`, and let `G=EE^T`, so `M_Q=E^TWE`. Full row rank and `M_Q^2=cM_Q` imply

\[
WGW=cW.
\]

Since every retained `w_i` is nonzero,

\[
GW=cI_N.
\]

Consequently:

- `G_ij=0` for every `i!=j`;
- `G_ii=T` gives `w_i=c/T=1/N`.

Therefore equality for a real point-evaluation rule requires

\[
L_a(x_i,x_j)=\langle\Phi_a(x_i),\Phi_a(x_j)\rangle=0
\quad(i\ne j),
\]

with exactly `N` nodes and **uniform positive weights**.

### Equality characterization

> An arbitrary signed atomic rule can attain the abstract block-trace rank floor only if it is actually an equal-positive-weight `N`-point zero code for the feature kernel `L_a`.

This is a meaningful strengthening: signed cancellation cannot attain the relaxation boundary.

## 4. New theorem target forced by the equality characterization

The remaining gap can be attacked by bounding how close an `N`-point spherical configuration can come to a zero code simultaneously for the comparison profiles. Equivalent formulations include:

- lower bounds on the off-diagonal energy of `L_a^2`;
- bounds on the idempotence defect `||M_Q^2-(T/N)M_Q||`;
- spherical-code bounds for the zero set of `L_a`;
- joint catalecticant or Hankel constraints linking moment matrices from different profiles;
- sphere-ideal constraints on multiplication operators.

The current certificate treats the lower bound for each profile separately. A joint realizability theorem could exploit the fact that all profile matrices arise from one signed moment functional `Q(fg)`.

## 5. What is and is not closed

**Closed:** no strengthening is possible from matrix rank and individual harmonic block traces alone.

**Open:** quantify the distance between the abstract projection and the variety of signed spherical evaluation moment matrices.

**Not implied:** exact Kerdock optimality, positivity of all optimizers, or a finite-width result.
