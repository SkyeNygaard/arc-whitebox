## Additional critiques addressed

- **Novelty:** related work is now explicit and claims are phrased as kernel-specific and model-specific contributions, not discovery of general integration limits.
- **Infimum vs minimum:** arbitrary-node T22 uses “infimum”; attainment is claimed only for the auxiliary LP and restricted support problems where proved.
- **Line vs point budget:** T27 uses line budget and explains that a symmetrized line normally uses two antipodal evaluations.
- **Signed mass:** defined on the consolidated measure using Jordan negative mass.
- **Metric normalization:** raw MSE, cross/noise-corrected MSE, adjusted score and oracle ratios are separated.
- **Effective sample size:** rotations are grouped by base network throughout.
- **Harmonic claims:** presented as a taxonomy of exact null spaces, frozen failures and open live-degree families.
- **Finite-width theorem:** restricted to the exact Gaussian-first-layer ensemble model and an explicit nondegeneracy condition.
