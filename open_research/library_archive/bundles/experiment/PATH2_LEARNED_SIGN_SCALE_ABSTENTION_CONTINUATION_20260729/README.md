# Path 2 continuation bundle

This compact bundle contains the reports, frozen protocols, feature tables, exact scale-quadratic summaries, analysis scripts, and ledger additions for the learned sign/scale/abstention continuation.

Bulky regenerable QMC reference arrays, vector caches, and execution logs are intentionally excluded. Their immutable protocols and result summaries are included.

Primary entry points:
- `PATH2_CONTINUATION_REPORT.md`
- `PATH2_CONTINUATION_SUMMARY.json`
- `results/FINAL_BOUNDED_CANDIDATE_RESULTS.json`
- `results/FRESH_SCALE_HOLDOUT_RESULTS.json`
- `protocols/fresh_holdout36/IMMUTABLE_HOLDOUT_PROTOCOL.json`
