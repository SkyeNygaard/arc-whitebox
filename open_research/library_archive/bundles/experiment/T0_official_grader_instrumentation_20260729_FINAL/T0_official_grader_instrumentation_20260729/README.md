# Tree T0 — Official Grader and Operating-Point Instrumentation

## Executive result

T0 is locally exhausted but **not officially closed**. The exact official grader stack, official cohort, and submission interface are absent. All remaining measurements have therefore been converted into seven immutable packages and a deterministic runbook rather than mislabeled projections.

### What is closed locally

- Four basis-count packages (129/96/64/32) are built and reproduce the implementation harness digest-for-digest.
- Two full-width synthetic timing sweeps show near-linear execution (`R²=0.997641`) and safe memory.
- Historical exposed-data evidence gives MSE scaling exponents 1.214–1.244; because these exceed one, the local adjusted frontier favors 129 bases. This is a prior, not the official answer.
- The no-op calibration arm is output-identical on two complete networks and differs by exactly 2.147483648B intended tracked FLOPs.
- A42/A43 are locally bit-identical; A43 saves 0.524123904B tracked operations and reduces peak memory by about 82.7%.
- Every historical cost gate has been repriced against the current ~174.5B operating point. A generic +14B method now needs at least 1.08023× raw-MSE gain before wall effects.

### Decisions

- **T0.1: BLOCKED.** Proxy evidence says preserve 129; official four-arm curve is still decisive.
