# Agent 2 strengthening report

## Objective

Strengthen the T22/T23 claims without leaking beyond their estimator class. The work targeted the exact weaknesses identified by the hostile audit: construction trust, implementation monoculture, hard-coded sign narration, intermediate-artifact coverage, and release provenance.

## Results

### 1. Explicit real-MUB construction

A clean implementation using Python integer arithmetic reconstructs the field chirps from `GF(2)[x]/(x^7+x+1)`. It exhaustively checks all nonzero inverses and multiplication permutations, all Walsh row inner products, all 128 distinct chirps, and all `128 choose 2 = 8,128` chirp-basis pairs. Every pair-product Walsh spectrum has absolute value exactly 16. The resulting normalized cross-inner-products are therefore exactly `1/16`.

The reconstructed chirp array exactly matches `kerdock_mub5_seed3.npz` from all seven archived production-package copies. This closes the gap between the abstract MUB incidence used in T22 and the actual asset used by the estimator.

### 2. Independent arithmetic path

The pure-Python `_pydecimal` implementation regenerated four canonical outputs byte-for-byte: the assembled interval certificate, sign-logic audit, Kerdock multiplicity proof, and spherical kernel-mean certificate. Three representative one-interval curvature chunks at indices 550, 605, and 606 also regenerated byte-for-byte.

A separate no-import scalar checker recomputed the exact coefficient sum, Delsarte bound, five-value Kerdock energy, mean subtraction, and one-sided ratio using pure `_pydecimal` outward rounding. Its narrower intervals overlap and are contained by the shipped conservative intervals. It obtains ratio upper bound `1.000233655010294813770660200...`, below the published rounded bound `1.0002336550102949`.

### 3. Sign-chain hardening

The original sign verifier encoded a nine-entry endpoint-sign table. The new verifier derives critical-point types, endpoint derivative signs, curvature signs, region coverage, and candidate maxima directly from the certificate fields. It independently recovers maxima 0, 2, and 4 and the same global upper bound `-1.0045862406584556e-13`.

### 4. Provenance and manifest hardening

The strengthened manifest covers every package file except the manifest itself, including all 23 intermediate curvature chunks. Its verifier also rejects unexpected files, preventing an incomplete manifest from silently describing only a selected subset. A separately distributed archive SHA-256 binds the release bytes.

## Stronger conclusion

It is now defensible to call T22 a reproducible computer-assisted theorem whose point-set incidence is explicitly certified and whose key downstream arithmetic has implementation-diverse replication. The claim should not be upgraded to formally verified, universal signed/adaptive optimality, or finite-width optimality.

The highest-value remaining proof-engineering task is a full second-engine regeneration of the 1,079 curvature intervals, ideally with MPFR/Arb or a proof assistant. Cross-platform CI is valuable but less mathematically load-bearing.
